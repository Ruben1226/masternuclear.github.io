# ⚛️ Portal del Máster Interuniversitario en Física Nuclear (UCM)

Plataforma web personal moderna, luminosa y optimizada para dispositivos móviles diseñada para centralizar tus asignaturas, semanas intensivas presenciales y a distancia, fechas límite de entrega, exámenes y recursos del **Máster en Física Nuclear (Facultad de Ciencias Físicas - Universidad Complutense de Madrid)**.

Preparado para publicar gratis en **GitHub Pages**.

---

## 🌟 Contenidos & Plan de Estudios Incorporado

### 1. Obligatorias (18 ECTS)
- **Estructura Nuclear: Propiedades y Modelos** (Sede: Granada / Madrid)
- **Introducción a las Reacciones Nucleares** (Sede: Sevilla)
- **Física Nuclear Experimental** (Sede: Madrid / UCM - Lab de Física Atómica y Nuclear)

### 2. Optativas Elegidas (18 ECTS)
- **Física Nuclear Aplicada I (Materiales y Medio Ambiente)** (Sede: Sevilla - CNA)
- **Radioprotección** (Sede: Salamanca)
- **Técnicas Experimentales Avanzadas en Física Nuclear** (Sede: Madrid / Valencia)
- **Física Nuclear Aplicada II (Energía y Aplicaciones Biomédicas)** (Sede: Madrid - UCM / CIEMAT)
- **Astrofísica Nuclear** (Sede: Barcelona - UB)

### 3. Trabajo Fin de Máster (24 ECTS)
- Trabajo tutelado en la UCM / CIEMAT / CSIC con defensa oral pública ante tribunal.

## 📱 Experiencia Móvil & Estética con Luz

- **Luz y claridad por defecto**: Fondos blancos y neutros luminosos, sin tarjetas saturadas de números pequeños.
- **Barra inferior móvil táctil**: Navega con comodidad con una sola mano entre *Inicio*, *Materias*, *Calendario*, *Enlaces* y *Notas*.
- **Fechas claras**: Cada tarjeta destaca de un vistazo la semana a distancia, la semana presencial con su sede, y el límite oficial de evaluación/examen.
- **Exportador a `.ics`**: Sincroniza todas las fechas oficiales directamente con Google Calendar o el calendario de tu smartphone.
- **Buscador instantáneo (`Ctrl + K`)**: Encuentra temas o asignaturas al instante.

## 🚀 Despliegue en GitHub Pages (3 Pasos)

1. Crea un repositorio en [GitHub](https://github.com/new).
2. Sube los archivos:
   ```bash
   git init
   git add .
   git commit -m "Inicializar portal master fisica nuclear"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/NOMBRE_REPO.git
   git push -u origin main
   ```
3. En tu repo en GitHub ve a **Settings** > **Pages** > selecciona rama `main` y carpeta `/ (root)` y pulsa **Save**.
